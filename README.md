# Telegram-бот для автоматизации взаимодействия сотрудников Urent и ЦОДД

Telegram-бот предназначен для автоматизации взаимодействия между сотрудниками ЦОДД и скаутами Urent через их координаторов.

Система позволяет создавать и распределять задачи, контролировать их принятие и выполнение, отслеживать статусы, а также получать фото-подтверждения от исполнителей.

## Пример задачи

```text
ОБРАЩЕНИЕ ГРАЖДАН

Коллеги, просьба убрать самокаты у ООТ «Ледовый дворец».

Координаты: 55.635823, 37.587351 (Чертаново)

Цель — оперативно решить поступившую задачу.

Отправлено скаутам на зоне!

Номер задания: #82430

Статус принято:    ❌ ❌ ❌
Статус выполнено:  ❌ ❌ ❌
```

По мере принятия и выполнения задачи соответствующие статусы изменяются.

В случае отмены задания дополнительно отображается причина:

```text
ЗАДАНИЕ ОТМЕНЕНО ПО ПРИЧИНЕ: <причина>
```

## Основные сущности

* **Задача** — обращение, которое необходимо обработать и выполнить.
* **Зона** — участок города, за которым закреплены определённые скауты Urent.
* **Слот** — информация о рабочем статусе скаута, определяющая, кто и в какой зоне работает в данный момент.
* **Скаут** — непосредственный исполнитель задачи.
* **Сотрудник ЦОДД** — пользователь, создающий задачи.
* **Координатор** — руководитель скаутов со стороны Urent, контролирующий выполнение задач.

## Основной функционал

* ролевая модель пользователей:

  * администратор;
  * скаут;
  * координатор;
  * сотрудник ЦОДД;
* создание и передача задач от сотрудников ЦОДД активным скаутам;
* мониторинг координатором статуса выполнения задач;
* таймер на принятие задачи — **5 минут** по умолчанию;
* таймер на выполнение задачи — **60 минут** по умолчанию;
* отправка скаутами фото-подтверждений выполненной задачи;
* автоматическое определение зоны по координатам задачи;
* автоматический выбор списка доступных скаутов в соответствующей зоне;
* редактирование зон через загрузку файла, экспортированного из конструктора карт Яндекса;
* возможность отмены задачи координатором с обязательным указанием причины.

## Стек технологий

* **Python**
* **aiogram** — взаимодействие с Telegram Bot API;
* **Peewee** — ORM для работы с базой данных;
* **PostgreSQL** — хранение данных.

## Развёртывание

Для упрощения установки проект дополнительно обёрнут в Bash-установщик.

Установщик:

* устанавливает необходимые для работы приложения зависимости;
* подготавливает окружение;
* упрощает первоначальную настройку;
* позволяет быстро развернуть систему на Unix-подобной ОС.

Таким образом, базовое развёртывание бота на подготовленной Unix-подобной системе занимает несколько минут.
